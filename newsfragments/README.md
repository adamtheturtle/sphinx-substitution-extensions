# Release notes

Add user-facing changes in `newsfragments/<issue>.<type>.md`, using an issue or pull request number.
The available types are `change`.
Use `+name.<type>.md` for changes without an issue number.

Write GitHub-compatible Markdown, including inline code, explicit links, and lists.
Towncrier writes one Markdown file per version and rejects invalid fragment names.
GitHub publishes that file directly as the release description.
